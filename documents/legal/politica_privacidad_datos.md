# Política de Privacidad y Protección de Datos Personales

**Código:** LEG-POL-2026-01  
**Alineación:** GDPR (UE), Ley 1581 (Colombia), LFPDPPP (México)  

## 1. Compromiso de Protección de Datos
En NovaGPU Technologies garantizamos la máxima privacidad de la información recolectada de nuestros empleados, clientes, distribuidores y visitantes web.

## 2. Tipo de Datos Tratados
- Datos de colaboradores: Identificación, historial laboral, datos bancarios para nómina, registros de salud ocupacional.
- Datos de clientes: Nombre, correo corporativo, dirección de entrega, historial de compras de hardware.
- Telemetría de GPUs (Opcional): Datos de uso térmico y frecuencias de reloj para optimización de drivers mediante software NovaControl (solo bajo consentimiento explícito opt-in).

## 3. Derechos ARCO (Acceso, Rectificación, Cancelación y Oposición)
Cualquier titular de datos puede ejercer sus derechos enviando una solicitud formal al correo `privacidad@novagpu.tech`. La respuesta se emitirá en un plazo máximo de 10 días hábiles.
